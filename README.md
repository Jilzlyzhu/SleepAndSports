# 作息星球 K-means 学习智能体

面向高一年级的 40 分钟交互课堂，依据《学习智能体-设计文档》和《K-means聚类—你是哪种作息星人？-教学设计简案》制作。沿用此前“湖畔实验室”的分步学习、教师证据看板和常驻导学结构，教学内容改为睡眠与运动。

## 立即体验

- 双击 `public/offline.html`：完整离线学习，无需安装、联网或密钥。
- 网页试用：点击“无需课堂码，先体验”，或访问 `index.html?mode=experience`。只填姓名和班级即可；本机体验与正式课堂分别保留记录。
- 有 Node.js 20 或以上：双击 `启动预览.cmd`，浏览器访问 `http://localhost:4186`。
- 教师端：在运行服务的电脑打开 `http://localhost:4186/?view=teacher`，**自动进入，无需填写教师口令**。会话过期自动恢复。
- 远程教师入口仍校验身份；其口令在首次启动的 `data/teacher-access.txt`，或通过 `TEACHER_KEY` 配置。本机免口令仅接受直接访问 localhost，不接受代理转发；`NODE_ENV=production` 或 `ALLOW_LOCAL_TEACHER=false` 会禁用本机自动进入。
- 教师创建班级后，发给学生课堂码和入口链接。学生填写姓名、与教师创建一致的班级名、课堂码。
- 教师端创建课堂后，**页面顶部大字显示“学生课堂码”**；可复制课堂码或学生链接，投屏模式也保留。学生链接自动填好班级与课堂码，只需输入姓名。刷新保留选中的班级。
- 班级可删除并从“已删除班级”恢复。删除后停止加入、保存与图鉴访问，保留学习记录。
- 教师端“配置大模型 API”可接 DeepSeek、火山方舟及兼容服务；“生成封面与卡片插画”支持豆包 / Seedream，先预览再应用。密钥只在服务端保存。详见 [大模型与插画接入](docs/大模型与插画接入.md)。
- 本机体验教师页不会生成正式课堂码，会明确显示“尚未生成正式课堂码”；点击“进入正式教师端，生成课堂码”后登录并创建课堂。
- 正式课堂码须由教师工作台创建。随意填写 `test01` 不会创建课堂；无课堂码时请选择体验入口。离线页点击首页或教师入口仍保留本机模式。
- WorkBuddy 部署：阅读 [WorkBuddy部署说明](docs/WorkBuddy部署说明.md)；源码和部署包不包含教师凭据或学生数据。

离线模式只保存当前浏览器的记录，教师页也只显示本机记录。启动课堂服务后支持不同设备同步，5 秒刷新。在线 AI 需要部署者配置模型服务，未配置时明确标注“本地导学”。

## 课堂流程

| 环节 | 活动与证据 |
|---|---|
| 情境导入 · 2分钟 | 满格/蓄能/待机三选一投票，教师看真实参与者的投票汇总 |
| 项目探究 · 17分钟 | 固定参考尺度标准化；定 k、初始化、分配、更新、重复、收敛六步；独立计算一次距离平方并选归属，再独立求 B 簇均值 |
| 项目实施 · 16分钟 | 40个明确标识的教学模拟样本，k=2/3/4，多起点运行，自动记录中心与成员数；至少比较两个 k，写选择理由 |
| 成果与自测 · 5分钟 | 命名→反馈→输入个人睡眠运动→41点重新聚类→与原猜测对照→反馈→五项自评，下载个人 PNG 卡片 |

错误作答不给正确数值，提供两层方法提示。首次独立完成、订正后完成、提示后完成分开记录。主观的 k 理由只检验是否提交，不自动声称“理解正确”；教师在证据表查看原文。教师开放环节不会伪造完成状态。

教师可选择一份学生方案定格为班级展示成果。课后图鉴保留匿名的聚类方案，不公开个人作答；课后访客输入仅在浏览器计算，可生成个人卡片。

## 数据和计算口径

- 手算 8 点与文件一致。默认初始中心从真实样本中选择：A=P2(7,7)、B=P5(7,1)、C=P7(2,1)，第一轮更新为 A′=(8,6)、B′=(8,5/3)、C′=(2.5,1.5)。界面允许 B 的纵坐标填 1.7。停止条件按未舍入中心移动量小于 1e-8 实现。
- 初始中心只能选择三个不同的整数样本，避免手算小数距离；更新后的中心按真实均值计算，不要求落在样本点上。每个手算步骤都有“上一步”，可点击已到达步骤回看；回看不改变计算进度。更换起点开启新一轮距离与均值任务，旧作答在学生和教师页面保留，后续 40 点实验与个人成果不删除。
- 40点采用固定的连续分布样本，包含中间过渡和边界位置，不预设三组类别或人数。学生比较 k=2/3/4 时需解释粗分、细分及边界归属的取舍，k=3不是标准答案。`public/data-40.csv` 提供原始时长与映射分数。**这是模拟数据，不是真实班级数据。**
- 睡眠 `(h-6)/3×10`，运动 `min/90×10`。参考范围内映射到 0–10；超出范围线性外推，图表扩展，两轴保持相同尺度，不截断个人数据。
- 正常实验每次运行24组随机起点，保留组内更紧凑的结果。同一批样本、相同种子可复现，换种子可能改变局部边界。自动验证 k=2/3/4 各100个种子均收敛、无空簇、中心为真实均值，不再用“恢复预设三类”作为正确性标准。
- 新样本版本为 `continuous-v2`。旧版实验、选择理由、命名与自测成果会归档供学生及教师下载，新版从比较 k 重新开始；前面的投票和手算不重置。已定格图鉴继续使用原样本；新旧成果不会混在一张图上。
- 自测将个人点加入后重新计算，用新旧中心整体最接近的对应关系继承簇名。对照导入名称采用粗略特征规则：睡眠分≥5且运动分≥4为满格、睡眠分≥5且运动分<4为蓄能，其余为待机。这只是本课的对照规则；k≠3时不强行宣称一一对应，不作健康诊断。
- “与你同簇”计数只指40个教学样本中同簇的点；实际参与人数单列。

## 文件与维护

- `public/`：零外部 CDN 的静态前端，可直接静态托管。
- `public/config.js`：课堂服务地址与刷新配置；不放模型密钥。
- `public/engine.js`：算法、样本、标准化、核验规则，浏览器与服务端共用。
- `public/tutor.js`：导学提示与模型约束；计算未通过时用方法提示，防止助教提前代答。
- `public/store.js`：本机存储与 HTTP 接口适配，待同步草稿保存本地，网络恢复重试。
- `public/features.js`：班级删除恢复、模型设置、插画工作台与图片加载。
- `ai-service.js`：服务端模型配置、DeepSeek兼容对话接口、Seedream兼容图片接口。
- `server.js`：可选参考服务，无第三方依赖；课堂认证、隔离、投票、保存、教师看板、成果快照、模型代理。
- `Dockerfile`：支持容器托管的平台可使用；并非声称所有 WorkBuddy 环境都支持此运行方式。
- `tests/`：算法和接口自动化测试；`scripts/smoke.cjs`、`scripts/offline-smoke.cjs` 为浏览器验收。

修改静态文件后执行 `npm run build` 更新离线文件和数据表。运行 `npm test` 核验算法与接口。运行服务仅需 `npm start`，没有 npm 安装步骤。

## 交付边界

已完成教学交互、参考课堂服务和本机验收；未访问或部署用户的 WorkBuddy 应用，未伪造其 SDK 或数据库接口，未连接真实模型。只有静态网页上线时，多设备汇总和在线 AI 不会自动生效。WorkBuddy 原生云函数方案需按接口说明接入其真实项目资源；容器方案需持久卷与 HTTPS。参考文件存储仅用于单实例课堂部署，多实例需改接云数据库。
