# WorkBuddy 部署与接入说明

本项目已完成前端与可运行的参考课堂服务。由于本次没有提供现有 WorkBuddy 应用链接、SDK、数据库或托管规格，交付不虚构“免密钥云服务已接通”。请根据你已有应用的实际能力选择以下方式。

## 方式一：先部署静态体验

将 `public/` 的内容作为网站根目录，入口 `index.html`。所有资源本地提供，无外网 CDN。没有课堂接口时自动进入“本机体验”，学生完整教学流程和个人卡片仍可用，记录只在各自浏览器。`offline.html` 是强制本机模式的单文件，双击即可体验。

单独静态托管不具备跨设备同步，也不具备真正的大模型能力。不能把浏览器本地汇总当成全班实时数据。

## 方式二：托管参考课堂服务

若你的托管资源支持 Node 或容器：

1. 导入本项目，运行时 Node.js 20以上，启动命令 `npm start`，默认监听4186，也支持环境变量 `PORT`。容器配置已给出。
2. 公网部署设置 `NODE_ENV=production`，禁用仅用于本机预览的自动教师入口。远程教师身份用 `TEACHER_KEY` 配置，勿写入前端；也可在后续云适配时对接平台已有登录。设置 `DATA_DIR` 为持久目录，并将其挂载到持久存储。只运行一个实例，勿将数据目录置于临时容器层。
3. 配置网站 HTTPS。若页面与API同源，`public/config.js` 保留 `apiBase:''`；若异源，`apiBase` 填 API 根地址，后端 `APP_ORIGIN` 填页面的完整来源（协议＋主机＋端口，无末尾斜杠）。
4. 在正式教师端“配置大模型 API”设置对话和图片服务，详见 [大模型与插画接入](大模型与插画接入.md)。也可用 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY` 初始化对话服务，图片使用 `IMAGE_BASE_URL`、`IMAGE_MODEL`、`IMAGE_API_KEY`、`IMAGE_SIZE`。密钥只保存在服务器，不放到 `config.js` 或任何浏览器文件中。保存的教师配置优先于环境变量；持久目录要同时保留配置文件与 artwork 图片目录。
5. 教师进入 `?view=teacher`，登录、创建班级，把班级名称、课堂码、学生链接发给学生。

创建成功后，课堂码显示在教师页顶部，投屏模式保持可见；“复制学生链接”带上了班级与课堂码。若页面提示“本机体验 / 尚未生成正式课堂码”，进入正式教师端后再创建。教师电脑以 localhost 打开的地址不能直接发给另一台设备；部署后从正式网址打开教师页再复制链接。

未配置模型或调用失败时仍可教学，消息明确标注本地导学。模型请求只带课堂上下文、匿名输入与问题，不带学生姓名；对话内由学生主动写入的个人信息仍属于问题内容，教师应按实际模型服务管理。

## 方式三：接入 WorkBuddy 原生云能力

若原有应用使用 WorkBuddy 云函数与云数据库而不运行 Node 服务：保留 `public/`，按 [接口契约](接口契约.md) 实现同名接口，或者修改 `public/store.js` 将这些方法映射到该项目实际 SDK。

把 `public/engine.js` 与 `public/tutor.js` 复用到服务端：算法核验不要信任浏览器自行宣称通过；AI的系统约束不要只放前端。数据库建议分为 classrooms、students、sessions、snapshots；学生凭会话只能读写自己的记录，教师读取课堂汇总与个人证据，图鉴只公开已定格的匿名方案。不要开放匿名用户查询全体学生原始记录。

参考服务将教师口令与会话校验放在服务端，会话凭据不在数据库明文保存。云适配需保留这个权限语义。课堂码仅用于加入班级，不能当教师凭证。接入现有云能力时，可改用平台自身身份机制，但要保持同样的数据边界。

## 上课前验证

- 用两台不同设备加入同一个课堂，看教师端投票与进度是否都增长；不同课堂的票数应分开。
- 检查 AI 消息来源：真正连接时显示 AI 学习助教，未连通时显示本地导学。
- 独立计算任务答错应不泄露正确数值；提示后完成应单独记录。
- 模拟临时断网后作答，恢复网络，确认记录重新同步；教师定格后云端拒绝后续改写。
- 选择方案定格，另一浏览器访问课后图鉴，应只能看到匿名成果。
- 实测机房显示分辨率与下载个人卡片。做好课堂数据备份，按学校规则确定保留时间。

首次启动生成的 `data/` 是运行数据，请勿把它上传到静态网站或提交到公开仓库。交付压缩包已经排除了运行数据、教师口令和测试记录。

## 本机预览免口令

在运行服务的教师电脑打开 `http://localhost:4186/?view=teacher` 会自动建立教师会话，不显示口令框，会话过期自动续接。服务端同时校验本机连接、localhost来源及无代理转发；公网生产模式不启用此能力。远程教师入口保留身份校验，不会对任意互联网访客开放全班记录。
