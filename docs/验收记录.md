1. 必须完成一次距离归属判断、一次均值计算和选择k的说明。
2. 使用40点预置模拟数据，明确注明教学样本；最后加入个人数据重新聚类。
3. 优先交付可运行项目，用户稍后部署到 WorkBuddy。
4. 不展示原水质主题、总误差术语或旧版出口条任务。
5. 个人卡片统计的是同簇教学样本，不能宣称等于真实班级同型人数。
