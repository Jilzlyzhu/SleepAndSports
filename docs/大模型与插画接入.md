# 星伴与作息图鉴接入说明

## 在教师端配置

运行课堂服务，打开教师端，点击“配置大模型 API”。对话与图片是两套独立服务，可只启用其中一种。API Key 不需要发到聊天中，直接填在教师配置窗口。保存后不回显原密钥，留空表示保留；更换地址时需同时换密钥。

| 用途 | 服务商 | 基础地址 | 模型 |
|---|---|---|---|
| 星伴对话 | DeepSeek | `https://api.deepseek.com` | 默认 `deepseek-flash`，以账号当前可用模型为准 |
| 星伴对话 | 火山方舟或其他兼容服务 | 方舟为 `https://ark.cn-beijing.volces.com/api/v3` | 填支持对话的模型名或接入点 ID |
| 图鉴与卡片插画 | 豆包 / Seedream（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | 填控制台可用的 Seedream 图片模型或接入点 ID |
| 其他图片服务 | 兼容图片生成 API | 服务商的 HTTPS 基础地址 | 须支持 `/images/generations` 和 `response_format: b64_json` |

基础地址不包含末尾的 `/chat/completions` 或 `/images/generations`，程序会自动补上。对话模型不能直接用于生成图片。图片尺寸默认2048×2048，可按所选模型的支持范围调整。

勾选启用并保存。对话服务可点击“测试已保存的对话连接”；图片服务用一次实际生成验证。测试与生成会按服务商计费。未配置或对话服务失败时，星伴自动改用明确标注的本地提示。独立手算任务未通过时只给方法提示，不向在线模型请求答案。

## 选择 k 的理由反馈

学生比较至少两种 k、填写理由后，点击原有“保存方案，准备展示”，星伴会使用已配置的对话模型，结合已保存的实验中心、成员和样本坐标分析理由。理由框下显示“已有依据、还可补充、想一想”，学生可修改后再次保存获取反馈。修改理由、切换 k 或重新实验会使旧反馈失效；刷新可恢复与当前方案匹配的反馈。

反馈仅作为修改建议，不判定通关、不设置唯一正确的 k，教师仍复核理由。发送给模型的是教学样本、实验记录和学生理由，不带姓名、班级或其他聊天记录；学生主动写入理由的个人信息仍属于文本内容。未配置模型、离线或请求失败时明确显示本地提示，保留原有保存与后续学习流程。

## 封面与个人卡片

选择一个班级，点击“生成封面与卡片插画”，选择用途与风格。支持班级封面，以及满格、蓄能、待机三个特征对应的卡片插画；风格包括纸艺、水彩、微缩星球。

生成后先预览，点击“应用这张插画”才显示给学生。同类插画供班级复用，不会在每位学生进入或刷新时收费生成。个人卡片按本次结果的特征选择插画；插画只是装饰，不是新的分类证据，也不等同于学生自选的簇名。姓名、时长和分组结果仍由程序绘制，下载 PNG 时合并插画。

班级封面在定格后的课后图鉴显示；相应卡片插画同时用于正式课堂个人卡片及课后自测卡片。已发布图片可重新生成、预览后替换。生成失败保留已应用的旧图。公共图鉴访客不能触发生成。

图片提示词使用固定场景、风格和类型，不包含学生姓名、班级名称或个人时长。生成图片有 AI 来源标记。数据散点图与表格始终由程序绘制。

## 配置存储与部署

- 配置存于 `DATA_DIR/ai-settings.json`，仅教师接口可修改，接口只返回是否已保存密钥；学生页面和静态文件不含密钥。该文件包含服务器使用的原始密钥，应像其他服务端密钥一样保护。
- 图片保存到 `DATA_DIR/artwork/`，由受控接口读取；未发布图片仅教师可见，班级内学生只可读本班已发布图片，定格图鉴允许读取对应已发布图片。删除班级后停止访问，恢复后重新开放。
- 部署包不包含上述运行配置、密钥或图片。部署时需挂载持久目录并重新配置 API。
- 可用环境变量初始化：`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`；图片为 `IMAGE_BASE_URL`、`IMAGE_MODEL`、`IMAGE_API_KEY`、`IMAGE_SIZE`。教师端保存过配置后，以配置文件为准。
- 仅静态托管或离线单文件使用本地提示，不调用模型，也不保存 API Key。公网部署保留教师身份校验。
- 参考服务为单实例；代理对图片生成请求应允许至少110秒超时，且响应体上限应足够容纳图片。

## 班级删除与恢复

选中班级，点击“删除当前班级”，核对名称与学生人数后确认。删除会从列表移除班级，并停止课堂码、学生保存和课后图鉴访问；学习记录与图片保留。教师在“已删除班级”中恢复即可继续使用原课堂码、记录和图鉴。离线体验同样支持删除和恢复。

## 核对与测试边界

接口参数已对照 [DeepSeek 官方入门文档](https://api-docs.deepseek.com/) 和 [火山方舟图片生成接口](https://www.volcengine.com/docs/82379/1541523)。模型名称和支持尺寸随服务商变化，以实际账号控制台为准。

本次验证使用模拟模型响应，覆盖密钥不回显、失败回退、图片预览与应用、跨班级访问限制、封面显示和带图卡片下载；未使用真实 API Key，也未产生真实模型调用费用。填写自己的密钥后，在教师端测试对话并生成一张图片即可确认实际连通性和画面质量。
