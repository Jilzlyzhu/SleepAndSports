# 课堂接口契约

基础路径 `public/config.js` 中的 `apiBase + /api`；JSON 请求响应。通常要求 `Authorization: Bearer <token>`；health、join、teacher/login、atlas 可匿名请求，teacher/local-login 按本机访问条件校验，artwork 的权限见下表。失败返回非2xx状态和 `{ "error": "面向用户的说明" }`。

| 方法 | 路径 | 输入 | 输出 / 语义 |
|---|---|---|---|
| GET | /health | 无 | `{app:"sleep-kmeans",version:"1.2.0",localTeacher:boolean,ai:boolean,images:boolean}`，app字段用于前端确认服务类型 |
| POST | /teacher/login | `{key}` | `{token}`，教师身份，12小时有效 |
| POST | /teacher/local-login | `{}` | `{token}`，仅非生产模式中教师电脑直接访问localhost可用；拒绝远程主机、跨源、代理转发；12小时有效，前端自动恢复 |
| POST | /teacher/create | `{name}` | `{code,name,unlocked:0,frozen:false,votes:[0,0,0]}` |
| POST | /join | `{name,className,code}` | `{id,token,state,room}`；className须与该课堂一致，返回新学生状态 |
| GET | /me | 无 | `{id,state,room}`，room中votes是本班三种猜测人数 |
| POST | /save | `{state}` | `{ok:true,updatedAt}`；仅写当前学生，核验计算、重算实验、冻结时拒绝 |
| POST | /chat | `{event,question,context}` | `{text,source}`；服务端使用持久化的学生上下文，context不作为可信事实 |
| GET | /teacher | 无 | `{rooms:[room],students:[{id,code,state}]}`；必须教师身份 |
| POST | /teacher/unlock | `{code,stage:3}` | room；仅开放页面，不写学生完成状态 |
| POST | /teacher/freeze | `{code,snapshot}` | room；保存匿名快照并冻结课堂 |
| POST | /teacher/unfreeze | `{code}` | room；恢复课堂模式 |
| GET | /atlas?code=... | 课堂码 | `{name,snapshot}`；仅返回已定格的匿名成果 |
| POST | /teacher/delete | `{code,confirmName}` | 教师删除班级，设置 deletedAt；保留记录，停止学生与图鉴访问 |
| POST | /teacher/restore | `{code}` | 恢复班级和原课堂码 |
| GET/POST | /teacher/ai-settings | POST为 `{kind:"chat"或"image",settings}` | 教师服务配置；返回 hasKey 而不返回 apiKey |
| POST | /teacher/ai-test | `{}` | 测试已保存的对话模型，返回回复或明确错误 |
| POST | /teacher/artwork/generate | `{code,kind:"cover"或"card",type:0/1/2,style:"paper"或"watercolor"或"space"}` | 教师生成草稿图片，返回图片元信息；card需type |
| POST | /teacher/artwork/apply | `{code,id}` | 应用本班当前预览图片 |
| GET | /artwork?id=... | 图片ID | `{dataUrl}`；教师可看草稿，学生仅看本班已发布图，定格图鉴可公开读已发布图 |

GET /teacher 新增 deletedRooms，rooms 仅包含未删除班级，含当前插画与预览元信息；students 排除已删除班级。GET /me 的 room 和 GET /atlas 顶层包含已发布 artwork（cover、cards），不包含密钥和图片草稿。图片二进制存于服务端 DATA_DIR/artwork，不写入学生 state。模型 settings 包含 enabled、provider、baseUrl、model、apiKey，图片另含 size；留空密钥保持原值，clearKey显式清除，更换地址需新密钥。生产地址限HTTPS，不跟随重定向传递密钥。

`/chat` 的 `event:"reason"` 使用已保存的理由与实际实验记录进行专项分析，可附 `reasonKey` 核对方案版本；版本不匹配返回409，避免把旧方案的回复用于新理由。反馈不改变完成状态。学生状态的可选 `reasonReview` 保存反馈与对应方案标识；保存时剔除与当前方案不匹配的反馈。

## 学生状态

规范结构以 `public/engine.js` 的 `newState()` 为准；典型字段：

```json
{
  "version": 2,
  "datasetVersion": "continuous-v2",
  "name": "学生姓名",
  "className": "高一（3）班",
  "stage": 0,
  "completed": [false, false, false, false],
  "vote": null,
  "normalized": false,
  "step": 0,
  "exploreView": 0,
  "handRound": 0,
  "handHistory": [],
  "centers": [[7,7],[7,1],[2,1]],
  "labels": [-1,-1,-1,-1,-1,-1,-1,-1],
  "evidence": {
    "distance": {"attempts":[],"hints":0,"passed":false},
    "mean": {"attempts":[],"hints":0,"passed":false}
  },
  "experiments": {},
  "k": 3,
  "reason": "",
  "names": [],
  "named": false,
  "selftest": null,
  "selfRatings": [],
  "messages": []
}
```

开始分配时记录 `initialCenters`。距离尝试 `answer:{value,cluster}`，均值尝试 `answer:{x,y}`；每条还含 `passed,hints,at`。服务端重算passed。提示使用量只增不减；通过与首次独立作答不是同一个概念。

`step` 保存本轮最远进度，`exploreView` 仅控制回看页面（-1 表示标准化）；回看不会改动计算中心、完成状态或作答证据。`centerDraft` 保存待选起点，选项必须为三个不同的 HAND 样本。`handDrafts` 保留当前距离和均值输入。

更换起点时将当前轮的 `round,initialCenters,evidence,step,centers,labels,repeatCount,converged,completed` 追加到 `handHistory`，`handRound` 加一，当前手算重新开始；40点实验与个人成果保持。后台核验历史连续性、禁止移除或改写既有作答，允许断网期间多轮一次补传。旧版记录保留原起点和判分依据，不将旧答案套用到新默认中心。每轮最多1000次作答、最多100轮归档，不静默截掉历史。

`experiments[k]={seed,result,at}`，result含centers、labels、迭代frames；服务端根据固定样本、k、seed重算，不使用浏览器上传的计算结果作为权威。

`datasetVersion` 标记40点样本。缺省表示旧版 `three-clouds-v1`，升级到 `continuous-v2` 时把旧的 experiments、reason、names、selftest、selfRatings 和后两环节完成状态保存在 `previousDataset`，清空新样本对应的实验与结论；手算证据不变。GET /me、GET /teacher 提供升级后的视图，保存时落盘；已有新版记录拒绝旧浏览器用无版本的状态覆盖。旧实验可单独下载，不能当作新样本的学习证据。

`selftest={sleep,move,point,result,cluster,type,at,feedback,feedbackSource}`，服务端重新标准化、将个人点加入40点后运行，再按中心匹配继承编号。

`snapshot={datasetVersion,k,centers,labels,names,reason,participantCount,frozenAt}`，只包含40个模拟样本的群体结果、方案理由与真实参与者总数，不含学生姓名、个人时长、聊天或作答历史。没有 datasetVersion 的历史快照按旧样本显示和自测；新快照必须带当前版本。

## 并发与运行方式

参考服务为单实例文件持久化，写入串行且通过临时文件重命名。学生端保存串行，轮询5秒，断网草稿缓存并重试。教师端输入或展开详情时暂停自动重绘，以免打断阅读。

云数据库适配应使用事务或版本字段，避免多实例覆盖；数据库访问必须在服务端按身份过滤，不采用“匿名可查询全部学生”的规则。生产部署自行配置日志、备份、访问控制及数据保留策略。
